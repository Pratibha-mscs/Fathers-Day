# Your photos go here 📸

These five images appear as taped polaroids around Anjalee's storybook.

Right now they are **placeholders**. To use your real family photos, simply
replace each file, keeping the **same file names**:

| File | Where it shows | Current caption |
|------|----------------|-----------------|
| `1.jpg` | top-left | "you & me ✿" |
| `2.jpg` | middle-left | "all of us, home" |
| `3.jpg` | bottom-left | "where it began" |
| `4.jpg` | top-right | "the mountain days" |
| `5.jpg` | bottom-right | "still going ✦" |

Tips:
- Keep them as `.jpg` with the same names (`1.jpg` … `5.jpg`) and they'll appear automatically.
- Portrait photos look best (they're shown in a 4:5 frame).
- To change a caption, edit the `PHOTOS` list near the top of `../storybook.js`.
